# 无实际效果戒律参考

## 筛选口径

本文件只收录同时满足以下两项的戒律：

- 没有接入任何游戏事件、状态维护、命令流程或心情结算效果。
- 戒律定义与态度文案均未表达可辨认的规则、价值取向或行为意义。

仅缺少自动触发效果、但仍有明确态度含义的戒律不属于本文件范围。

## 当前结果

检查 `ideology.yml` 中注册的 28 条戒律后，当前没有符合上述双重条件的项目。所有已注册戒律都有明确的标题、戒律描述和态度立场；其中部分由游戏事件或状态管理器实际处理，其他未接入行为的项目仍表达了具体规则含义，因此不列为“无效果且无意义”。

后续如新增符合条件的戒律，仅在此记录其内部 ID、名称，以及确认其没有实际效果和明确意义的依据。戒律补入行为处理或补齐含义后，应从本文件移除。
