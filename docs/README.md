## 文档约定

- [玩法说明](玩法说明.md) 面向玩家；[使用文档](使用文档.md) 面向服主；[插件机制说明](插件机制说明.md) 解释实现规则。
- 配置和数值以服主服务器上的实际文件为准。每个功能都可能受模块开关、依赖、角色权限和战争状态限制。
- “已配置模因或戒律”不代表该定义已有游戏效果；实际接入边界以机制说明和使用文档为准。
- 发现文档与当前源码不一致时，请通过[项目问题跟踪页](https://github.com/stoleyourharvs/WorldDynamics-Engine/issues)报告具体页面和行为。
