# 万邦演变引擎：玩家玩法说明

> [Wiki 首页](README.md) · [角色背景与信仰菜单](背景与信仰菜单使用说明.md) · [服主使用文档](使用文档.md)

> 本文面向玩家与国家管理者，介绍 WDER 中的角色、治理、外交、战争与国家集团玩法。具体模块是否开放、费用和规则数值以所在服务器设置为准。
> 服主安装和配置请参阅[使用文档](使用文档.md)。
## 1. WDER 是什么
WDER 建立在 Towny 之上，为城镇和国家增加治理、外交、集团与战争玩法。Towny 仍负责居民、城镇、国家、领土和原生金库；WDER 不替代 Towny 的建镇、建国、圈地或地块管理。
主要关系是：
```text
居民 → 城镇 → 国家 → 国家集团
```

城镇和国家是治理主体，国家可以加入国家集团。国家职位、集团身份和玩家个人身份并不相同，因此能否执行操作取决于所属国家、职位、当前政体和具体规则。

输入 `/wde` 打开主菜单；输入 `/wde help` 查看命令帮助。游戏内帮助支持点击翻页，也可用 `/wde help <页码>` 跳转。

默认玩家可以使用所有正常玩法命令，无需额外申请指令权限；管理其他玩家、城镇或国家时仍必须具备对应游戏内身份。`/wde admin`、`/wde debug` 和 `/wde reload` 是管理入口，不属于默认玩家权限。

## 2. 角色背景

若服务器开启背景系统，可通过 `/wde background` 选择或查看背景。

背景分为两个阶段：

1. 儿童时期
2. 成年时期

必须先完成儿童时期，才能选择成年时期。每个阶段只能选择一次，确认后不能更改。背景会展示个人故事和配置的成长加成；技能加成需要服务器安装并启用对应的 AuraSkills 集成才会生效。

若服务器开启强制选择，未完成两个阶段的玩家可能会在登录时被要求打开菜单，并在完成选择前受到移动限制。可使用以下命令查看状态或背景：

```text
/wde background status
/wde background list <childhood|adulthood>
/wde background info <childhood|adulthood> <id>
```

## 3. 文化与信仰
使用 `/wde ideology` 浏览文化，也可用 `/wde ideology list` 查看列表、`/wde ideology info <名称>` 查看详情。
玩家可以选择个人文化。首次选择免费，之后改信通常需要支付费用。现在玩家侧不再提供“清空为无文化归属”的入口；在 GUI 中，每名玩家同一时间只保留一个当前个人文化。服务器可能配置文化联盟改信折扣，最终费用以确认界面和系统提示为准。
玩家也可以创建新文化。创建者会自动成为该文化的追随者和领袖，并支付创建费用。文化领袖可以设置模因和戒律；戒律态度由整个文化共享，不是每名追随者各自选择。
已经担任任意文化领袖的玩家不能再次创建文化，创建入口会被禁用，也不会扣费。交出所有领袖职位后才能再次创建；改信或放弃信仰不会自动解除领袖职位。
模因整组修改和单条戒律修改都支持冷却。冷却天数在 `ideology.yml` 中配置，可按现实天或 RealisticSeasons 天计算；若配置为季节天但环境不可用，会自动回退到现实天。模因冷却期间不能再次整体改写该文化的模因，戒律冷却期间也不能再次切换同一条戒律的态度。
每个文化都有独立的教廷金库。任何玩家都能向它献金，献金使用默认货币，存入后永远不能取回；包括文化领袖在内，没有任何玩家能够取款。在信仰详情中点击“教廷金库”即可查看余额和献金。
文化领袖只能设置每日定额什一税，额度为 0 时停征。每个 Towny 新日结算后，按当前个人文化向全部信徒征收，包括离线玩家和领袖。税额以默认货币计价，余额不足只收现有资金，不形成欠税。城镇和国家的文化不会替代个人文化来征税。

玩家可用 `/wde gift <玩家> <金额> [币种]` 直接向在线玩家赠送自选金额；不指定币种时使用默认货币。资产比较会将双方所有可用、已配置币种按汇率折算为默认货币。受赠者转账前的折算资产严格低于赠与者一半时，赠与按赠与者的仁善态度结算心情；同一赠与者向同一受赠者的仁善心情奖励默认每 30 分钟最多一次。

折算资产低于对方一半的在线玩家可用 `/wde alms <玩家>` 请求施舍；请求不填写金额。目标可自行决定赠与金额并使用 `/wde alms accept <申请者> <金额> [币种]`，也可用 `/wde alms reject <申请者>` 拒绝。双方须保持在线；请求默认 5 分钟过期，同一对玩家默认 10 分钟内不能重复申请。拒绝有效请求时，支持仁善的拒绝者会受到心情扣减；同一对玩家的拒绝扣减默认 24 小时最多一次。赠与、申请间隔和仁善惩罚间隔可在 `config.yml -> economy.playerGifts` 与 `ideology.yml -> mood.doctrineActions.kindness` 调整。

仪式完成时，主持人及其范围内实际参与的同信仰玩家按各自“仪式”态度结算；“推崇”态度获得默认持续 30 分钟的“仪式满足”，反感/厌恶态度参与时受到违背扣减。每名“推崇”玩家若连续 30 个现实日没有亲自参与完成仪式，会获得持续心情扣减，直到再次参与完成仪式；取消的仪式不计入。持续时间、缺席天数和功能开关位于 `ideology.yml -> mood.doctrineActions.rituals`。

```text
/wde ideology treasury <名称>
/wde ideology donate <名称> <金额>
/wde ideology settithe <名称> fixed <每日金额>
```

模因和戒律帮助描述文化立场，但定义出现在菜单中不代表对应玩法已经实现。护甲、进食和动物击杀等行为会按个人信仰的戒律遵守情况增减心情；每条适用戒律分别计算，心情范围为 0～100。动物杀戮戒律中的无辜动物是不会攻击或反击玩家的动物。违反已接入戒律时，服务器可能显示可配置提示。

“动物共鸣”的“强力”态度下，玩家击杀动物按违背值扣减心情，成功喂食动物按符合值获得加成；“无”态度不结算。喂食仅在右键动物后确认手持物品实际减少或消失时计入，普通右键不会发放奖励。击杀时动物共鸣会与“宰杀动物”“杀戮无辜动物”等适用戒律分别结算。心情按 `mood.decayMinutes` 衰减，开关位于 `ideology.yml -> mood.doctrineActions.animalResonance.enabled`。

拥有“动物平权”模因的玩家会定期观察周围 8 格内被拴绳控制的动物；每只动物在持续处于观察范围时只触发一次默认 `-5` 心情，离开范围后再次进入可重新触发。玩家亲自解除动物拴绳时获得默认 `+5` 心情。两种变化均持续 5 分钟；检测半径、间隔、数值和时长可在 `ideology.yml -> mood.doctrineActions.animalPersonhoodLeash` 配置，也可单独关闭。

服务器会把已映射的食物分为素食、肉食、人肉、血食，包含自定义食品。已配置食人戒律时，人肉只受食人戒律约束，不触发肉食戒律的加成或惩罚；未配置食人戒律时，人肉才回退到肉食戒律判定。血食由独立的血食戒律判定。没有信仰、没有相关规则或食物未分类时心情不变。

心情变化会按态度极端性放大：态度的 `moodChange.compliant/violation` 分别定义符合加成和违背扣减，最终乘以 `moodWeight`（0～10，默认 1）。预置态度中，中立类为 `0/0`，其余为 `1/1`；动物击杀和食用人肉只有在态度未显式设置数值时，才继承 `ideology.yml -> mood.instantActions` 的基础值。这些瞬时行为的变化默认持续 30 分钟后消散。护甲属于长期行为，依据装备、信仰和态度事件更新一条持续心情修正，不会定时消散；态度菜单会显示符合加成与违反扣减的预计值。

饮用药水时会按“药水”戒律结算临时心情：“禁止”态度违反任何饮用行为；“仅医疗”只认可含有益效果且不含负面效果的药水；“医疗或社交”和“必须”认可饮用药水。后两种态度饮用“醉生梦死”名单中的药水时额外获得默认 +10 心情，随 `mood.decayMinutes` 衰减。名单在 `mood.doctrineActions.potions.inebriationPotions` 配置：原版填 `PotionType` 名称，CE 填完整物品 ID；CE ID 指定的是药水物品本身，不是药水效果。另用 `craftenginePotionItems` 声明其它 CE 自定义药水物品，额外加成数值可用 `inebriationMoodBonus` 调整。

“枭示”戒律每 40 tick 检查玩家周围默认 8 格三维范围内是否有已放置的原版头颅或墙上头颅。“渴望”态度在有头颅时符合，“反感”态度在没有头颅时符合；状态变化会替换长期心情修正，不会按扫描次数叠加。检测间隔和范围可在 `mood.doctrineActions.displayOfHeads.checkIntervalTicks` 与 `radiusBlocks` 调整；物品栏及掉落物中的头颅不计入。

照明戒律按玩家脚下方块的光照判断：白天有效光照为 `max(blockLight, skyLight)`，夜晚忽略天空光、只取 `blockLight`。`0` 为无光，`1–6` 为昏暗，`7` 为中间状态，`>7` 为明亮。“中立”无心情修正；“微光”要求有效光照 `<7`，“渴求”要求 `>7`。正好 `7` 对两种态度都既不符合也不违反，不产生心情变化或违规提示；符合与违反其他状态时才按态度配置加减心情。光照改变时替换长期状态修正，不会每次移动或检查重复叠加。检测开关与间隔位于 `ideology.yml -> mood.doctrineActions.lighting`。

“室内”戒律使用玩家脚下方块的天空光判断：“喜爱”态度下，天空光 `<10` 判定为室内并按遵守值加心情，天空光 `>=10` 判定为室外并按违反值结算。状态变化时替换唯一的长期心情修正；检测开关与间隔位于 `ideology.yml -> mood.doctrineActions.indoors`。

采矿戒律只在玩家成功破坏配置的矿石或石头方块时结算，默认列表包含 `STONE`、主世界各类矿石、下界石英/金矿和远古残骸。原版方块使用 `mood.doctrineActions.mining.ores.vanilla` 中的 Bukkit `Material` 名称；CraftEngine 自定义方块使用 `.ores.craftengine` 中的完整 ID（例如 `ores:ruby_ore`），需要 CE 集成可用。每次采矿按个人戒律态度结算，并遵循心情变化的默认衰减时间；配置开关为 `mood.doctrineActions.mining.enabled`。

“野战”戒律中，“喜好”态度的玩家在 Towny 未认领的野外地块交战时获得心情加成。攻击玩家/生物或受到其他玩家/生物伤害会进入战斗状态；之后每次战斗触发都会刷新计时，30 秒无新触发则脱离战斗。每段连续战斗只奖励一次，避免连续命中反复累加；开关和超时时长可在 `ideology.yml -> mood.doctrineActions.fieldBattle` 设置。

“传教”戒律在玩家通过普通个人改信加入已有文化时触发：该信仰所有未被开除的个人信徒（包括新人）共享一次临时正向心情，数值按传教态度配置，随 `mood.decayMinutes` 衰减。符合值为 0 时不发奖励；离开信仰不扣心情，管理员强制分配和崩溃改信不触发。功能开关为 `ideology.yml -> mood.doctrineActions.proselytizing.enabled`。

“舒适”为“漠视”时，成功睡在床上会按态度违背值扣除临时心情；连续累计在线 3 个 Minecraft 日未睡觉，则按态度符合值获得长期加成，成功睡眠后清除。默认符合/违背均为 1；无态度不结算。阈值可在 `ideology.yml -> mood.doctrineActions.comfort.noSleepThresholdDays` 调整，功能可通过 `enabled` 关闭。

“餐风露宿”的“接纳”态度下，完成露天睡眠会按符合值获得心情加成，并按 `mood.decayMinutes` 衰减。系统记录入床位置，只有床上方无遮挡、且服务器确认睡眠完成后才结算；室内睡眠、未成功入睡或中途取消均不触发。开关为 `ideology.yml -> mood.doctrineActions.roughingIt.enabled`。

伐木戒律会在玩家破坏白名单中的原木/树干时结算；种树戒律会在玩家成功放置白名单树苗时结算。两者均记录独立临时心情并按 `mood.decayMinutes` 衰减。原版列表分别位于 `mood.doctrineActions.logging.wood.vanilla` 和 `mood.doctrineActions.trees.saplings.vanilla`；对应的 `.craftengine` 列表支持 CE 木头方块 ID，以及树苗物品 ID或放置后的方块 ID。默认木头列表不含木板或完整木方块。

畜牧戒律在玩家成功繁殖动物时结算：个人态度为“主要”时按符合值获得心情加成，“反对”时按违背值扣减；“无”态度不产生变化。每次成功繁殖独立结算并按 `mood.decayMinutes` 衰减；没有玩家繁殖者的自然繁殖不会触发。功能开关为 `ideology.yml -> mood.doctrineActions.ranching.enabled`。

“牵绊”会按玩家拥有的驯服生物提供长期心情加成，默认每只 +2；驯服生物死亡时移除它带来的加成，并额外获得 -4、持续 7 天的心情变化。插件会记录之后驯服的生物，并在区块加载时逐步发现旧存档中已有的驯服生物，因此尚未加载/发现的旧宠物暂不计入。“痛苦”为“理想”时，当前血量低于最大血量的 75%/50%/25%/10%会分别获得 +2/+4/+6/+10“甜美的疼痛”；血量达到 75% 时获得 -2“不安”。“痛苦”为“无”或没有有效个人文化时，仅在低于这些阈值时分别扣除 2/4/6/10。痛苦心情是当前血量状态修正，只保留一个最深档位，血量变化后替换，恢复后清除；不按检查次数重复累加。数值、血量阈值、检查间隔和宠物死亡持续天数可在 `ideology.yml -> mood.doctrineActions` 配置。

“多元文化”按每名居民自己的个人文化，统计同一 Towny 城镇中其他有效信仰居民的人数（不含本人、无信仰者；每个人单独计数）。偏见类态度对每名异信仰居民分别产生一次扣减，认可类态度分别产生一次加成，中立态度无变化；单次数值仍由态度的 `moodChange` 和 `moodWeight` 决定。该效果按当前城镇人口维护长期修正，人数或信仰改变后替换，不会随检查重复累加；离线居民也参与统计。开关和检查间隔在 `ideology.yml -> mood.doctrineActions.multiculturalism`。

心情每分钟判定一次：低于 50 时每低 1 点有 2% 崩溃几率；高于 50 时不会按差值掷灵感几率，而是在 `mood.inspiration.intervalMinutes`（默认 2 分钟）到期且心情仍高于 50 时，从当前可用的启用灵感中随机获得一个。基础灵感包括射击（下一次箭矢命中无视目标一半护甲）和近战（下一次近战命中无视目标一半护甲）；拥有“自然至上”模因时，随机池会加入驯服灵感；黑暗亲和模因加入夜莺灵感，抽中后立即获得默认 15 分钟夜视；传教热忱加入劝慰灵感，右键其他在线玩家可给其 +10 临时心情；裸体主义加入行动激励，抽中后立即获得默认 15 分钟速度 III；地底之心加入挖掘激励，抽中后立即获得默认 15 分钟急迫 III。以上药水持续时间可分别在 `mood.inspiration.effects.nightingale.durationMinutes`、`actionIncentive.durationMinutes` 和 `miningIncentive.durationMinutes` 调整。驯服灵感可用于一次有效驯服尝试并保证成功，或喂养一只成年、可繁殖动物，使其单独产下一只幼崽；两种用法都会消耗一份匹配物品和一次待用灵感。待用次数会持久保存，可在 `/wde mood` 查看。候选灵感等概率抽取：基础灵感都启用时，每个含灵感效果的已选模因增加一个候选；选中一个、两个、三个、四个、五个相关模因时，其专属灵感概率分别为 1/3、1/4、1/5、1/6、1/7。开关位于 `ideology.yml -> mood.inspiration.effects`。崩溃按剩余心情分轻度（34～49）、中度（17～33）、重度（0～16），并随机触发该级启用的效果：悲伤徘徊、暗黑之视、疯言疯语、紧张性木僵或信仰危机；信仰危机只随机改信一次。普通崩溃结束后获得默认 +40 心情“得到宣泄”，持续 30 分钟。崩溃时长、疯言疯语内容与间隔、宣泄加成均可在 `ideology.yml -> mood.collapse` 配置。

在原有崩溃效果之外，“苦痛美德”模因会把第六种自我伤害 `self_harm` 加入重度崩溃候选；触发时玩家获得 5 秒凋零效果。拥有该模因时，崩溃候选受模因效果列表限制。

“动物平权”模因会加入专属崩溃“野性爆发”：玩家会逐组丢弃背包、快捷栏、副手和盔甲物品，直到物品栏清空；清空后崩溃结束。默认每 10 tick 丢弃一组，受保护插件取消掉落时物品会保留并继续尝试。该效果可在 `ideology.yml -> mood.collapse.effects.wildOutburst` 调整。

“苦痛美德”还会把拉伸灵感加入高心情随机池；抽中后 15 分钟内，方块与实体交互距离各增加 1 格。效果可由管理员使用 `/wde admin ideology moodclear <玩家> inspiration` 清理；离线后按到期时间恢复，不会重复叠加距离。六种相关模因都被选中且基础灵感启用时，每种模因专属灵感的概率为 1/8。

玩家在崩溃期间死亡会立即取消崩溃状态，不触发“得到宣泄”。死亡本人另外获得默认 +10、持续 `mood.decayMinutes` 的“重获新生”心情加成；数值可在 `ideology.yml -> mood.events.deathRebirthBonus` 配置。

如果你的个人信仰将“非人化”态度设为“必需”，每次自动心情崩溃都会固定进入“人性崩溃”：玩家获得失明，并依配置依次看到标题和聊天提示。流程结束后永久获得“非人化”标记，心情固定为 50，不再受任何心情加成或扣减影响；流程时长及每步提示可在 `ideology.yml -> mood.collapse.effects.humanityCollapse` 配置。

只有选择“非人异化”模因的文化才能将“非人化”戒律设为“必需”。戒律生效后，该文化中尚未非人化的信徒会持续受到 `-15` 心情的“耻于为人”修正；完成非人化、心情固定为 50 后，此修正随其他心情条目清除。修正按信徒状态维护，不会重复叠加。
## 4. 城镇治理
新玩家会按累计在线时间获得期望心情修正：默认 0～2 小时为“极低期望” `+30`，之后每 2 小时依次为“很低期望” `+24`、“低期望” `+18`、“合理期望” `+12`、“高期望” `+6`，10 小时起为“很高期望” `0`。Towny 镇长默认 `-8`、国家国王默认 `-12`；两种身份修正不叠加，兼任时只应用国王修正。`/wde mood` 会逐项显示新玩家档位、身份修正及合计值。阶梯和修正可在 `ideology.yml -> mood.expectations` 配置。
## 4. 城镇治理

城镇政体由城镇治理者管理。当前支持：

- `DICTATORSHIP`（独裁）：由城镇领袖任命镇长。
- `REPUBLIC`（共和）：通过提名和投票产生城镇领袖。

共和制的选举周期和投票期限由服务器配置。独裁制不显示选举相关信息。候选资格、投票资格和选举处理时间以菜单及系统提示为准。

玩家可使用 `/wde town <城镇名>` 查看城镇治理信息；使用 `/wde town` 或 `/wde town menu` 打开自己的城镇管理菜单。菜单会根据身份显示可用操作，普通居民不能因此获得城镇管理权限。

城镇管理者还可能管理本镇征召兵。征召兵必须是本镇居民，人数上限按人口比例计算；是否允许城镇参加 Towny 常规战争由服务器设置。部分城镇固定居民税由所属国家设置，仆从国还受自治等级的固定税额上限约束。

## 5. 国家治理

国家政体包括：

- `DICTATORSHIP`（独裁）：国王可任命治理领袖和军队统帅。
- `DEMOCRACY`（民主）：按服务器设置进行领袖和军队统帅选举。
- `NOBLE_COUNCIL`（贵族议会）：国王发起提名，由符合资格的城镇镇长投票。

各政体的候选人范围、投票人范围及任命方式不同。独裁制下不展示选举信息。民主制国家选举完成后，WDER 会尝试将新领袖同步为 Towny 国王，并将首都迁至其所属城镇。

国家管理者还可管理政府成员、外交官、军队成员和下属城镇税制。军队统帅负责军队相关管理；征召兵通常由所属城镇登记。实际操作资格以菜单和系统提示为准。
查看国家信息或打开管理菜单：
```text
/wde nation <国家名>
/wde nation
/wde nation menu
```
## 6. 外交与访问
国家可设置外交关系、开放或关闭贸易，并在允许时使用外交访问传送。可用命令包括：
```text
/wde diplomacy relations <国家名>
/wde diplomacy setrelation <国家名> <friendly|neutral|unfriendly>
/wde diplomacy trading <国家名> <enabled|disabled>
/wde diplomacy viewtrading <国家名>
/wde diplomacy visit <国家名>
```

关系态度与活跃战争不是同一状态。服务器可能通过贸易联盟制裁限制访问：
- 被制裁国不能使用相关贸易联盟成员国家的外交访问传送。
- 被制裁国与目标领土所属成员国之间没有活跃战争时，不能进入该成员国领土。
- 是否解除领土禁入按这两个国家之间的战争状态判断；与其他国家交战不会解除限制。

Towny 中立状态提供战争保护。受中立保护的国家不能发起、加入或成为战争目标，也不能加入军事同盟。已经参战的国家或城镇不能在战争中临时开启中立来退出战斗。使用独立借口也遵守这些限制。

## 7. 国家集团

国家是集团成员，玩家通过所属国家的授权职位参与集团事务。集团页面可从 `/wde` 主菜单打开，也可用 `/wde org` 或 `/wde org menu` 浏览。
WDER 支持四类集团：
### 贸易联盟
用于成员国之间的贸易与外交协作。获授权的国家代表可管理联盟制裁目标。制裁会限制被制裁国使用联盟成员的访问传送，并在双方未处于战争时限制进入相关成员国领土。
### 军事同盟
军事同盟成员国可发起宣战提案，由成员按集团规则投票。提案通过后才会进入战争；中立保护、停战期和战争参与条件仍然有效。
### 文化联盟
创建时绑定创建国的文化，只接收符合该文化条件的国家。该联盟的文化规则还会影响改信费用折扣及和平条款分数消耗。
### 主权帝国

由主席国和从仆国组成。一般从仆国分为三个自治等级：

- `DOMINION`：自治领，自治程度最高。
- `PROTECTORATE`：保护国。
- `PUPPET`：傀儡国，自治程度最低。

主席国可以在规则允许时调整从仆国自治等级、管理卫戍身份、要求参战、调整领袖或索取贡金。从仆国则可在镇压度、费用和战争状态等条件满足时提升自治等级。
主席国的帝国管理权止于国家层级，不获得从仆国下属城镇的治理权限。城镇治理仍由本镇管理者及所属国家依法管理。集团信息和仆从国菜单单独展示主席国，不把主席国列作仆从国。

自治提升的完整路径为：**傀儡国 → 保护国 → 自治领 → 和平独立**。自治领镇压度再次归零且本国未参战时，授权代表可在从仆国菜单点击“和平独立”，或执行 `/wde org promoteautonomy <帝国名>`。支付与自治升级相同的国库费用后，本国退出帝国，解除从属、贡税、卫戍与强制参战义务，不触发独立战争，也不需要主席国批准。和平独立不会删除国家或城镇，也不会自动改变既有外交关系。

卫戍国免除一般从仆贡税，征召兵容量为人口的 100%，并承担帝国常规战争义务。主权帝国战斗期间，只有卫戍国适用统帅附近巡检；若卫戍国在线玩家均未靠近统帅，服务器可按配置施加挖掘疲劳。被主席国调遣的一般从仆国仍须参战，但不受这项巡检 Debuff。

从仆国不能通过普通退盟立即离开主权帝国。执行退出会打开战争菜单，由玩家手动选择独立借口，向主席国宣战；独立发起方在战争中属于防守方，被挑战的一方为进攻方。城镇镇长也可向所属国家使用独立借口。独立借口使用普通战争计分和条约规则；进攻方占领独立发起方首都并持续达标后，可提交单条“允许独立”让步和约强制兑现。若进攻方当前未达到占领比例，独立方分数领先达到 `warGoals.defenderIndependenceScoreDifference`（默认 40）时，也可主动提交单条“允许独立”要求并强制独立。

## 8. 战争与和平条约

WDER 的常规战争可由国家直接发起；参加军事同盟的国家必须经过内部投票。可从 `/wde war` 菜单选择目标和理由，或执行 `/wde war declare nation <国家|组织> <理由> [目标城镇|组织]`。城镇战争需服务器允许，由镇长执行 `/wde war declare town <城镇> <理由>`；结束时可执行 `/wde war surrender town <敌镇>`。WDER 的战争状态与 Towny 的外交态度分别管理。

战争成功开始后，双方参战城镇的个人信徒都会按“战争”戒律获得持续状态修正，战争由城镇或国家发起均适用。“渴望”态度在战争期间获得符合加成，“厌恶”态度受到违背扣减，“中立”不变；战争结束后清除战争修正。连续和平达到默认 30 个现实日后，按相反态度方向维护长期和平修正：“渴望”扣减，“厌恶”加成。`mood.doctrineActions.war.longPeaceDays` 可调整和平时长，`enabled` 可关闭功能；开关位于 `ideology.yml -> mood.doctrineActions.war`。

“掠袭”的“重视”和“必要”态度要求本方在战争中提交有效的“索要”提案，并包含至少 5% 赔款或贡金条款；未提出时战争期间持续扣减，提出合格条款后转为符合加成。此记录按战争和受益方保存，即使提案被拒绝也保留。所有参战战争均满足才获得符合状态；连续 30 个现实日没有合格经济战争时转为长期和平扣减。阈值和开关位于 `mood.doctrineActions.raiding.longPeaceDays`、`mood.doctrineActions.raiding.enabled`。

参战时，双方玩家会看到当前专注战争的侧边计分板，展示我方与敌方的总分、占领分、击杀分和关键分账。若同时参加多场战争，可在 `/wde war` 菜单中切换专注战争，或执行 `/wde war focus` 查看编号后用 `/wde war focus <序号>` 切换。

战争理由由玩家手动选择，包括征服、收复失地、独立、圣战、贸易冲突、羞辱宿敌、输出革命、摧毁威胁。独立借口只供城镇向所属国家、仆从国向帝国主席国使用。圣战要求两国均已设置且彼此不同的文化，不能由无文化归属国家发起，也不能针对无文化归属或同文化国家。输出革命仅限民主制国家；收复失地要求敌方现在持有本国曾连续拥有超过规定天数的城镇（默认超过 7 天）；贸易冲突仅针对通过贸易联盟封锁本国的成员国；羞辱宿敌要求双方已相互敌对；摧毁威胁仅针对军事同盟或主权帝国主席国。菜单及命令补全只显示符合资格的理由，投票结束前会再次检查。
收复失地的天数可按现实天或 RealisticSeasons 日历天计算，缺失兼容季节记录时按现实天回退。多次短期持有不累计；旧数据没有可验证的历史，需从升级后开始记录。

所有 WDER 战争使用同一套周期计分：每国原始占领权重共 50 分，多城国家首都固定 25 分，其余 25 分按非首都城镇人口分配；单城国家或独立城镇拥有全部 50 分。全面和约的阵营基础占领分归一化为 50，单独谋和按对方国家领土的原始分数独立计算。
在防守方城镇，每周期按进攻方人数 / 双方总人数分给进攻方，其余分给防守方。无人驻守默认给防守方全额分。进攻方守住自己的城镇不加占领分；防守方反攻则按敌方城镇权重和人数比例获得额外分。各周期累加，不覆盖此前成绩。
有效击杀获得服务器配置的分数。只有防守方复活后冻结，期间不计入占领人数；进攻方没有死亡冷却。死亡和旁观模式玩家不计入人数。独立借口的发起城镇或仆从国为进攻方，原国家或宗主阵营为防守方。
战争开始与结束会在全服聊天栏播报。战争期间可以通过和平条约协商结束战争。国家国王可从主菜单或 `/wde org peacetreaty` 打开条约菜单；收到条约后可从 `/wde org reviewtreaty` 查看。菜单提供双方国家、分数差、要求或给予方向、条款编辑和提交确认。提交提案不代表对方已经接受。
条约可包含赔款、强制改信、转移城镇、解散或退出集团、解放从仆国、无条件通行权、羞辱、劫掠首都、每日固定贡金和允许独立等条件。贡金金额由条款直接指定，不再按税额比例计算；旧比例贡金协议会归零停征。条款有各自的分数成本，总分受服务器上限约束。实际生效条款可能进一步受到战争类型、受益对象、国家权限和当前状态限制。
“强制附庸”条款默认消耗 60 分，和约生效后让步国成为受益国所主持主权帝国的傀儡国，解除原宗主关系，不改变城镇归属。受益国必须是帝国主席国，目标不能是其他帝国主席国或已属于该帝国，也不能与允许独立或解散目标国家的割让同时使用。该条款不是单独指令即时附庸，仍须完成和平条约受理。
菜单只显示当前可用的条款、谈判国家和条款参数选项；没有可转移城镇或可解放从属国时，对应条款不会出现。赔款增减、翻页、加入条款及提交按钮仅在可操作时显示。独立借口不要求“允许独立”作为其他条款的前置条件。菜单刷新时会重新检查资格，并清理失效的草稿条款。
首都也可以被割让。割让首都后，剩余人口最多的城镇成为新首都，该城镇镇长继任国王；人口相同时按城镇名排序。若割让的是国家最后一座城镇，国家解散，城镇并入条款指定的受益阵营国家。会解散国家的条约自动取消贡金和通行条款，且不再计算这些条款的分数。
参战城镇或国家的玩家在战争期间不能使用 Towny 的 spawn 传送，包括城镇、国家及前哨传送；和平玩家不受这一限制，WDER 集结传送仍按自身规则执行。
全面和约处理战争双方的战争盟主；符合条件的成员国可以单独谋和并退出战争。单独谋和有额外分数惩罚。文化联盟对条款成本有特定修正：被宣战的战争盟主与联盟文化相同，成本会提高；对方为异教徒时，成本会降低。具体倍率由服务器配置。
普通“允许独立”条款须对方接受后生效：仆从国退出主权帝国，城镇退出所属国家成为独立城镇，不自动建国。满足独立战争的目标强制条件时，唯一的“允许独立”条款可按正常和约流程强制执行。城镇与国家谈判时仅展示适用于城镇的条款，国家专属条款不展示。使用独立借口仍受中立、停战期及城镇参战开关限制。
和约生效后，相关国家会进入停战期。停战期可以使用现实时间，也可以由服务器选择 RealisticSeasons 指定世界的日期计算；该可选集成不可用时按配置回退。

战争目标按理由自动对应：征服、收复失地要求夺取指定城镇；独立要求进攻方占领独立发起方（防守方）的首都/城镇；圣战、输出革命要求占领目标国首都；羞辱宿敌和取缔非法组织要求展现霸权。占领类目标要求进攻方在线占领人口比例严格超过 75%；霸权目标要求击败达到敌方开战时总人口数量的不同敌方玩家。目标连续达成超过服务器配置时长后，进攻方可提交仅含对应条款的和约并强制兑现。独立战争还有防守方主动兑现条件：进攻方当前未达到首都占领比例，且独立方分数领先达到 `warGoals.defenderIndependenceScoreDifference`（默认 40）时，独立方可提交单条 `DEMAND` 方向“允许独立”条款。进攻方目标达标时仍使用 `SURRENDER` 方向的“允许独立”；其他目标使用 `DEMAND`。军事同盟战争不提供强制和约；除该独立战争规则外，战争分差不代替目标判定。

目标对应条款为转移目标城镇、允许独立、强制改信、强制民主化、羞辱或解散目标组织。强制民主化由进攻方指定目标国一名非开战时国王的现任镇长成为民主制总统，目标国政体默认锁定 100 天；具体时钟由服务器配置，可使用现实天或季节日历天。普通和约仍由接收方审核。

## 9. 旅馆与死亡掉落

若服务器启用了 WDER 旅馆功能，玩家在 Towny 的 `INN` 地块内成功使用床位时，非本镇居民可能需要支付床位费；本镇居民免费。床位费和支持币种由旅馆经营者及服务器经济设置决定。

床上成功睡眠还会触发“舒适”戒律；“漠视”态度会扣除临时心情，并清除长期不睡觉获得的加成。该机制独立于旅馆收费，普通床和旅馆床均可结算。

若服务器启用了额外死亡掉落，玩家死亡时会在原版掉落之外额外抽取 WDER 掉落。CraftEngine 自定义物品仅在对应集成可用且物品已正确注册时生效。

## 10. 常见问题

**菜单里看得到按钮，但为什么不能操作？**  
菜单展示不等于拥有权限。国家职位、集团代表身份、选举阶段、战争状态、费用和其他前置条件都会在操作时重新检查。
**为什么菜单里的戒律没有实际效果？**  
文化定义和戒律态度可以用于展示与扩展，但只有接入了具体效果实现的戒律才会影响游戏行为。
**为什么不能在战争中开启中立或退出集团？**  
中立不能作为战争中的逃战手段；主权帝国从仆国退出会打开战争菜单选择借口，而不是无条件和平离开。
**在哪里查看具体费用和剩余分数？**  
以游戏内确认界面、集团/国家菜单和系统提示为准。服主可以调整相关费用、战争分数和停战期参数。

## 11. 常用入口速查

```text
/wde                         打开主菜单

```
部分功能可能因服务器关闭对应模块、缺少可选插件或权限不足而不可用。

## 集结传送

全国征召兵和本国各镇镇长可主动使用 `/wde rally nation`，传送到本国当前军队统帅的位置，由国库支付费用。
本镇征召兵可使用 `/wde rally town`，传送到本镇当前镇长的位置，由城镇金库支付费用。
`/wde` 主菜单会向符合身份的玩家显示对应集结按钮，点击后确认传送。

统帅或镇长必须在线且仍属于本国或本镇。费用由服务器决定，不能由玩家设置。
集结不是强制拉人；其他插件的传送限制仍然生效。目标不可用、金库不足、复活冻结或背景选择冻结期间不能传送。
传送取消时尝试退回费用。自己不能传送到自己，乘坐载具时也不能使用。
