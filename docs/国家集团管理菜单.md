# 国家集团管理菜单

> [Wiki 首页](README.md) · [国家集团与战争机制](插件机制说明.md) · [服主使用文档](使用文档.md)

## 入口

从 `/wde` 主菜单进入“国家集团”，或直接使用：

```text
/wde org
/wde org menu
/wde org menu <集团名称>
```

集团浏览页支持按类型筛选、分页，以及创建集团。创建时先选集团类型，再在聊天栏输入名称，确认后从本国国库支付创建费。名称输入在 60 秒内完成，输入 `cancel` 取消。

原有 `/wde org info <集团名称>` 和其他管理命令保持可用。

## 通用功能

每个集团采用 54 格大箱子管理界面，标题和专属内容随集团类型变化。

- 顶部展示主席国、创始国、成员数量、集团金库和维护费。
- 成员名册、入盟申请、制裁目标、战争提案和活跃战争分别分页，不共用页码。
- 授权的非成员国可申请加入；授权成员国可按规则退出。
- 主权帝国主席国没有退出按钮；从仆国退出按钮打开战争菜单，手动选择独立借口，不自动开战。
- 存款由玩家个人钱包支付，取款进入操作者个人钱包，使用默认货币。取款与解散仅向集团领袖或主席国授权代表提供。
- 操作先确认，再调用已有集团命令。原命令继续检查成员资格、角色、费用、中立保护、停战期和其他机制条件。

国王、政府领袖和军队统帅可以在符合原命令规则时代表所属国家；普通成员可浏览公共信息，但不获得国家级决策权限。国王可进入和平条款及收到的和约菜单。

## 贸易联盟

专属区域提供“当前制裁目标”和“选择制裁国家”。点击目标后可确认开启或解除制裁。

制裁规则会直接显示：被制裁国不能使用联盟访问传送；被制裁国与目标领土所属成员国未交战时，不能进入该成员国领土。其他战争不会解除这对国家的禁入限制。

## 军事同盟

专属区域提供宣战提案、待决战争投票和活跃战争。

宣战时选择目标国家，确认后提交集团内部提案，并非立即开战。战争投票详情展示提案国及成员国支持或反对状态；授权成员国可选择同意或反对，按原权重制度结算。

活跃战争展示进攻方、防守方和双方分数，可进一步进入和平条款菜单。中立、停战、成员和战时权限约束继续有效。

## 意识形态联盟

展示固定的联盟意识形态、相同意识形态准入规则、同教与异教的和平条款倍率。

改信折扣按当前国家真正能够享受的折扣展示。它可能来自该国参加的其他意识形态联盟，不是把多个联盟折扣相加；非成员没有本集团折扣。

联盟信仰按钮可进入现有意识形态详情，普通访客仍只能查看，不能因为打开集团菜单而修改信仰戒律。

## 主权帝国

### 帝国首页

首页包含：

- 主席国与从仆国名册。
- 主席国能力、一般从仆国合计能力、卫戍国合计能力。
- 自动贡税开关、金额和结算周期。
- 入盟申请直接审理入口。
- 活跃独立战争、分数和已结算周期。
- 从仆国授权代表的“我的从仆国档案”入口。
- 和平条款与收到和约入口。

一般从仆国与卫戍国分别比较各组总能力和主席国能力，不能将全部从仆国混在一起理解。

### 从仆国档案

名册中的从仆国可进入独立详情页，展示自治等级、镇压度、卫戍身份、参战义务、中立保护、治理领袖、军队统帅和意识形态。

页面另有镇压结算周期和增减规则、一般贡税、一次性强制贡金、强制动作降低镇压度的数值、固定税和财产税上限、下属城镇以及独立战争进度与规则。

| 操作 | 可操作身份 | 条件或后果 |
| --- | --- | --- |
| 降低自治等级 | 主席国授权代表 | 镇压度达到 100、等级可降低、无独立战争；同时限制城镇税率 |
| 设置或取消卫戍国 | 主席国授权代表 | 依现有规则切换身份；卫戍国免一般贡税、征召容量为人口 100%、承担参战义务 |
| 开启或解除强制参战 | 主席国授权代表 | 独立战争期间不能操作；卫戍国不能解除；中立保护阻止常规动员 |
| 强制更换领袖 | 主席国授权代表 | 选择目标国居民，独立战争期间不可操作；成功后降低镇压度 |
| 强制要求贡金 | 主席国授权代表 | 按目标国自治等级取配置金额，由目标国国库支付，进入集团金库；成功后降低镇压度 |
| 承认独立 | 主席国授权代表 | 仅在该从仆国已有独立战争时可用；确认后放弃镇压并立即承认独立 |
| 提升本国自治等级 / 和平独立 | 该从仆国授权代表 | 镇压度归零、无独立战争，从本国国库支付费用；自治领继续提升为和平独立，额外要求本国未参战 |
| 选择独立借口 | 该从仆国授权代表 | 打开战争菜单，向主席国手动宣战；遵守常规中立、停战与投票规则 |

不满足条件的主席国操作显示屏障及规则说明。确认时重新检查角色、集团对象、从属身份及状态；集团解散或同名重建后，旧菜单不能操作新的集团。承认独立后自动返回帝国首页。

自治领的提升按钮显示“和平独立”。确认后使用相同自治升级费，退出帝国并清除从属、贡税、卫戍与强制参战义务，返回集团页面，不触发战争；无需主席国批准。“选择独立借口”打开统一战争菜单，不自动开战，不受此和平机制替代。

## 配置与验证

新菜单文本位于 `message.yml` 的 `ui.orgmenu`。修改后执行 `/wde reload`，不会通过 GUI 修改服务器的全局规则配置。

金库金额、自治费用、贡税、税收上限和战争参数来自已有配置及管理接口。具体扣费、权重投票、独立战争和和约执行仍由原业务机制决定，GUI 不会代替这些校验。

目前已通过源码兼容性编译和模拟菜单检查；上线前仍需在真实 Towny 与经济插件环境验证创建、存取款、各类投票、独立战争和强制动作。
