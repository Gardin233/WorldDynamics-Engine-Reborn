# 背景与信仰菜单使用说明

> [Wiki 首页](README.md) · [玩家玩法](玩法说明.md) · [文化提示与图标](文化提示与图标配置.md)

## 玩家入口

| 指令 | 功能 |
| --- | --- |
| `/wde` 或 `/wde menu` | 打开角色与信仰首页 |
| `/wde background` 或 `/wde background menu` | 打开背景故事菜单 |
| `/wde ideology` 或 `/wde ideology menu` | 打开信仰与文化菜单 |

无需额外安装菜单插件或客户端模组。原有文字指令仍然可用，不新增 `/wde religion` 入口。

## 背景故事

1. 打开背景菜单，进入儿童时期的背景工坊。可搜索、翻页或浏览内置预设和其他玩家发布的作品。
2. 点击已有作品，在确认页阅读标题、完整故事和技能词条，再点击选择。`/wde background choose <childhood|adulthood> <id>` 也会打开确认页，不会直接选定。
3. 也可点击「空白创建背景」，填写标题、故事，用 `+` / `-` 为自动识别的 AuraSkills 技能分配点数。每段必须恰好分配 5 点，可集中或拆分。
4. 发布会将作品永久存入 `backgrounds.yml` 的 `community-backgrounds`，不等于选定。返回列表也不会撤销发布，其他玩家仍可使用它。
5. 每个阶段只能选一次。确认儿童时期后自动进入成年时期；两个阶段合计 10 点。完成后仍可浏览工坊或发布新作品。

玩家不能编辑已有作品。管理员可用 `/wde admin background edit <communityId> confirm` 修改已发布作品的标题和正文，作者、阶段和技能分配保持不变。更改影响后续选择，不改写已选玩家的快照或奖励。

编辑器和存档保留占位符原文；浏览和确认时按查看者解析 PlaceholderAPI（PAPI）变量。未安装 PAPI 时 `%player_name%` 仍可替换为查看者的名字，其他变量保留原文。

技能加成沿用原有 AuraSkills 联动：未安装或玩家技能数据尚未加载时，提示加成待发放，后续登录时尝试补发。列表显示配置的成长加成，并不表示缺少 AuraSkills 时仍能即时生效。

开启强制背景选择后，尚未完成选择的玩家登录时自动打开菜单；关闭 WDER 菜单后，会在短暂延迟后重新弹出背景菜单。原有移动限制保留。

## 信仰选择

1. 打开信仰菜单，点击选择 / 改信。
2. 浏览信仰列表，点击查看创立者、教主、模因和戒律态度。
3. 点击选择 / 改信，查看本次费用后确认。

首次选择免费，后续改信沿用既有费用规则与文化联盟折扣。费用在确认时重新校验；余额不足时不会完成改信。玩家侧不再提供“放弃当前信仰”为无文化归属的入口，菜单中同一时间只保留一个当前个人文化。

创建信仰时，在聊天栏输入名称，随后确认创建费用。输入不会广播给其他玩家。名称须为 2～24 个字符，只能包含字母（包括中文）、数字、下划线或连字符。输入 `cancel` 可取消，60 秒内未输入则超时。

创建成功后，创建者自动成为该文化的追随者和领袖，并进入新信仰详情。创建费用正常收取；创建者无需再次支付改信费用。

模因整组修改与单条戒律态度修改都受冷却限制，冷却天数与计时方式由 `ideology.yml` 配置。若启用 RealisticSeasons 天数模式但日历不可用，会自动回退为现实天。

## 教主管理

“管理我领导的信仰”会列出当前由你担任教主的信仰，不要求你本人信奉它。

模因页面支持勾选、取消、分页和保存，必须选择 1～4 个模因，不能互相排斥。保存前会展示已选模因供确认；更换后不符合新模因限制的戒律态度会自动调整。

戒律页面显示当前态度，点击可阅读全部态度说明。教主可以选择允许的态度并确认保存，受模因限制的态度显示为禁止选择。普通玩家只可浏览，不可修改；保存时重新检查教主身份。

戒律态度是整个信仰共享的设定，不是单个信徒的个人偏好。菜单展示所有已注册戒律，不意味着所有戒律均有行为判定。当前护甲、饮食和动物击杀戒律会按合规或违规行为调整个人心情；药水效果由模因心情效果决定，目前相关效果暂留空。

## 服主配置

背景系统的开关位于插件数据目录中的 `backgrounds.yml`：

```yaml
enabled: true
forceSelectionOnFirstJoin: true
```

不需要强制引导时，将 `forceSelectionOnFirstJoin` 设为 `false`。背景内容和技能加成仍在 `backgrounds.yml` 配置。

文化系统由 `ideology.yml` 中的 `religionEnabled` 控制。

菜单标题、按钮和提示集中存放在 `message.yml`；AuraSkills 技能译名可用 `lang/messages_<locale>.yml` 的 `background_skill_name_<namespace>_<skill>` 键覆盖，业务配置仍使用原始技能 ID。提示支持 `&` 颜色码；带 `%s` 的文本应保留对应占位符数量。

修改后执行 `/wde reload`。热重载会关闭旧菜单、取消待输入的创建流程并补齐缺失文本字段，不覆盖已有文本值。

## 上线检查

源码检查不能替代游戏内测试，建议在测试服务器依次验证：

1. 强制模式首次登录自动弹窗，未选完成前移动受限。
2. 完成儿童与成年选择后退出并重进，选择仍保留，技能加成不重复发放。
3. 首次改信免费，后续改信正确扣费，余额不足不改信。
4. 普通玩家只读；教主可修改；打开菜单后更换教主，旧教主无法提交。
5. 创建名称不出现在公共聊天，取消和超时能返回菜单。
6. 超过 45 条时分页正常；Shift 点击、数字键、双击和拖拽不能取走菜单物品。
7. 打开菜单时执行热重载，旧页面关闭，重新打开后显示新配置。
