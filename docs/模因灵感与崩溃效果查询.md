# 模因灵感与崩溃效果查询

本文根据 `ideology.yml -> memes.registry` 中的 `moodEffects.inspiration` 与 `moodEffects.collapse` 整理。这里的“无专属效果”仅表示没有在模因上显式配置对应效果 ID，不代表该模因持有者不会获得通用灵感或经历普通崩溃。

`inspiration` 和 `collapse` 均按 YAML 列表保存，可在同一模因下扩展多个效果 ID：

```yaml
moodEffects:
  inspiration:
    - effect_id_one
    - effect_id_two
  collapse:
    - effect_id_three
    - effect_id_four
```

运行时模型也按 `List<String>` 读取这些 ID。旧配置若仍以单个字符串保存，启动时会将其迁移为仅含该 ID 的单元素列表，不会覆盖现有列表或自定义 ID。

## 查询结果

- 注册模因：18 个。
- 显式配置专属灵感 ID：6 个。
- 未显式配置专属灵感 ID：12 个。
- 显式配置专属崩溃 ID：3 个。
- 未显式配置专属崩溃 ID：15 个。
- 两类专属 ID 均未配置：10 个。

## 无专属灵感 ID

以下 12 个模因没有在 `moodEffects.inspiration` 中声明 ID：

`original_sin`、`loyalty`、`supremacist`、`collectivist`、`ritualist`、`cannibal`、`bloodfeeder`、`nonhuman_alienation`、`raider`、`individualist`、`animal_personhood`、`human_primacy`。

这些文化仍可从启用的通用灵感中获得射击和近战灵感。只有显式关联专属灵感的模因，才会把相应模因灵感加入随机池；每种灵感还受 `mood.inspiration.effects` 开关控制。

## 无专属崩溃 ID

除 `ritualist`、`pain_is_virtue` 和 `animal_personhood` 外，其余 15 个模因均未在 `moodEffects.collapse` 中声明专属崩溃 ID。这不代表玩家不会崩溃：没有任何已选模因声明崩溃 ID 时，系统仍从当前严重程度对应的通用启用效果中选择。

`ritualist` 声明了 `dark_vision`。该中度崩溃会使玩家失明，并在持续期间循环播放恶魂环境音。

`pain_is_virtue` 声明了 `self_harm`。当所选模因中存在崩溃效果筛选列表时，崩溃候选会按所有已选模因声明的 ID 合并筛选；`self_harm` 仅作为重度崩溃候选。因此，若“苦痛美德”是唯一声明崩溃 ID 的已选模因，玩家发生轻度或中度崩溃时没有匹配候选，崩溃效果不会启动。

`animal_personhood` 声明了 `wild_outburst`，可在任何崩溃严重程度被抽中。效果会持续逐组丢弃主背包、快捷栏、盔甲、副手及光标中的物品，直到这些栏位清空；实际掉落物受 `PlayerDropItemEvent` 取消保护，取消时保留物品并继续尝试。默认每 10 tick 尝试一次；配置的 24 小时只作存档续期周期，背包未清空时会续期，重连后继续。

另有一条不由模因结果列表配置的特殊规则：个人“非人化”戒律态度为 `required` 时，崩溃固定进入 `humanity_collapse`。因此 `nonhuman_alienation` 虽没有专属崩溃 ID，玩家仍可能因其“非人化”戒律态度触发该特殊流程。

## 实现位置

- 模因专属 ID：`ideology.yml -> memes.registry.<meme_id>.moodEffects`
- 通用灵感与开关：`ideology.yml -> mood.inspiration.effects`
- 通用崩溃效果与开关：`ideology.yml -> mood.collapse.effects`
- 灵感随机池：`InspirationManager`
- 崩溃候选筛选：`MentalCollapseManager`
