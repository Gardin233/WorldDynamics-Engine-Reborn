# 意识形态提示与图标配置

> [Wiki 首页](README.md) · [背景与信仰菜单](背景与信仰菜单使用说明.md) · [意识形态机制](插件机制说明.md)

修改服务器插件目录中的 `message.yml` 或 `ideology.yml`，然后执行 `/wde reload`。旧配置缺失的字段会自动补齐，不覆盖已配置的值。

## 违背戒律提示

```yaml
ui:
  doctrine_violation: "&c你违背了自己的戒律，这让你的内心感到不安"
  doctrine_violation_cooldown_seconds: 30
```

提示支持 `&` 颜色码、`%player_name%` 玩家名称和 `%doctrine_name%` 戒律名称。将提示设为 `""` 可关闭文字，但不关闭戒律惩罚。

间隔按“玩家 + 戒律”分别计算。默认持续违反同一戒律时每 30 秒最多提示一次。

当前已接入穿着护甲戒律的实际违规检测；其他仅有定义而没有玩法效果的戒律不会凭空触发提示。外部效果可在服务器主线程调用 `getPlayerMenuManager().sendDoctrineViolation(player, doctrineId)`，共享配置与提示间隔。

## 图标

图标现在直接写在 `ideology.yml` 的模因和戒律定义里，不再单独放在 `message.yml`。

```yaml
memes:
  registry:
    original_sin:
      title: "原罪主义"
      description: "我们生来有罪。其他人比我们更有价值。"
      icon: SOUL_LANTERN
    custom_example:
      title: "自定义模因"
      description: "示例"
      icon: your_namespace:custom_icon

doctrines:
  registry:
    "namespace:wder/armor_wearing":
      title: "穿着护甲"
      lore: "对于身体遮蔽与护甲穿着的态度"
      icon: IRON_CHESTPLATE
```

图标可使用原版物品名称，也可直接填写完整的 CraftEngine 物品 ID。无效名称、空气、不能作为物品使用的材质，或当前未加载的 CE 物品，都会回退为程序默认图标。

戒律图标同时用于戒律列表和允许选择的态度列表。不允许选择的态度仍显示屏障。模因勾选状态通过说明文字展示，不替换自定义图标。

## 创建后的归属

通过命令或 GUI 创建新意识形态成功后，创建者立即成为该意识形态的追随者和领袖，个人归属写入持久化数据。

只收取创建费用，不再额外收取改信费用；此次自动加入计入已选择信仰，之后普通改信仍按既有收费规则处理。创建失败不会改变个人信仰。
