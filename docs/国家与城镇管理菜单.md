# 国家与城镇管理菜单

> [Wiki 首页](README.md) · [国家与城镇治理机制](政府与军队机制说明.md) · [服主使用文档](使用文档.md)

## 入口

输入 `/wde`，点击“国家管理”或“城镇管理”。也可以直接使用：

```text
/wde nation
/wde nation menu
/wde nation <国家名> menu
/wde town
/wde town menu
/wde town <城镇名> menu
```

省略名称时打开自己的国家或城镇。原有 `/wde nation <国家名>` 和 `/wde town <城镇名>` 保持文字信息展示，不改变旧命令行为。

## 国家管理

54 格大箱子顶部显示政体、治理领袖、军队统帅、意识形态以及政府、军队和城镇数量。可浏览其他国家和下属城镇；没有对应权限时不显示修改按钮。

| 身份 | 可见的管理操作 |
| --- | --- |
| 国王 | 修改政体；独裁、贵族议会制下任命或提议治理领袖；任命或提议军队统帅 |
| 政府领袖 | 添加、移除政府成员；民主制下提前开启选举 |
| 军队统帅 | 征召、移除军队成员；传送至本国征召兵或主席国统帅，实际资格由军队命令校验 |
| 国王、政府领袖、军队统帅 | 任命、撤销本国外交官；设置下属城镇居民税 |
| 国王、政府领袖 | 设置国家意识形态 |
| 本国居民 | 非独裁制且存在对应投票时，可以打开领袖或军队统帅投票列表；实际投票资格仍由业务规则判断 |

独裁制不显示选举、提前选举或军队统帅投票。民主制没有直接任命治理领袖的按钮。

设置居民税依次选择城镇、固定税或财产比例税，再在聊天栏输入非负数值。仆从国税率上限等规则仍由原命令校验。

## 城镇管理

顶部显示政体、领袖、意识形态、所属国家、居民税和征召兵容量。共和制额外显示选举周期，独裁制隐藏选举信息。

- 城镇领袖、镇长或有权管理该城镇的国王，可修改政体和城镇意识形态。
- 独裁制可选择本镇居民任命镇长。
- 共和制可修改选举周期；本镇居民在选举期或换届到期后可提名候选人，活跃选举期间可投票。
- 征召兵管理只对本镇治理领袖或镇长开放：选择居民后可征召、移除，并为已征召居民切换免税特权。
- 其他城镇可以浏览；仅在当前身份确有治理权限时才提供对应修改操作。

## 交互与校验

所有居民、候选人、国家、城镇和信仰选择列表均支持分页。需要数值时暂时关闭箱子，在聊天栏输入；输入 `cancel` 取消，60 秒未输入自动返回。

修改操作先进入确认界面，确认时重新检查当前归属和角色，再调用现有管理命令。命令继续校验政体、候选资格、城镇归属、征召兵容量、费用和税率限制。菜单不会绕过权限直接写入治理数据，也不会把命令返回值当作操作成功。

改信费用沿用当前配置和首次免费规则。确认执行后显示原命令的成功或失败提示，并刷新管理菜单。

## 配置

菜单文字位于 `message.yml` 的 `ui.management`；使用 `/wde reload` 生效。关闭治理模块时管理菜单不可用，军队和意识形态操作也遵循各自模块开关。

当前菜单覆盖 WDER 已有的常用国家、城镇治理命令，不替代 Towny 原生圈地、银行、城镇创建、删除等操作，也没有增加原命令不存在的主席国跨国征召兵调度页面。
